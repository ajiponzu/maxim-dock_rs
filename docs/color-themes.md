# カラーテーマ

設定画面の「Dock → カラーテーマ」で選択します。

- 標準：青をアクセントにした従来の配色
- Ocean：青緑
- Forest：緑
- Rose：ピンク
- カスタム：9色を個別に指定

プリセットは「システム／ライト／ダーク」の明暗設定に対応します。「この配色をコピーしてカスタマイズ」で現在のプレビュー色を編集の出発点にできます。カスタム色は明暗モードに関係なく固定です。

色ボタンまたはカラーコードをクリックするとカラーピッカーを開けます。カラーコードから開いたピッカーの下部では `#RRGGBB` を直接入力することもできます。変更はカード内のプレビューだけに即時反映され、「適用して保存」で Dock と設定画面全体へ反映・保存されます。「変更を破棄」で元に戻せます。文字の読みやすさはプレビューで確認してください。

## TOML で編集する場合

CSS は使用しません。アプリを終了し、既存の `config.toml` の appearance 部分を編集して再起動してください。既存の dock／items や ID は変更する必要がありません。

```toml
[appearance]
theme = "dark"                 # system / light / dark
background_opacity = 0.86      # Dock パネルだけの不透明度
palette = "custom"             # default / ocean / forest / rose / custom

[appearance.colors]
background = "#0F141D"         # 設定画面の背景
panel = "#18202D"              # Dock とカード
field = "#212C3C"              # 入力欄
border = "#344256"             # 境界線
text = "#EDF2FA"               # 通常の文字
muted = "#9BACC4"              # 補足文字
accent = "#5E9DFF"             # 選択・主要ボタン
on_accent = "#081830"          # アクセント上の文字
hover = "#284061"              # ホバー強調
```

既存の appearance テーブルにキーを追記し、同じテーブルを二重に定義しないでください。省略した色は既定のダーク配色になります。プリセット利用時もカスタム色は保持されますが使用されません。

色は6桁の16進数だけを受け付けます。CSS の色名・短縮表記・アルファ付き色・セレクター・レイアウト指定には対応しません。不正値や未知の palette は設定エラーとして扱い、元ファイルを保護します。実行中の外部編集を自動再読込する機能はありません。カスタム色のコントラスト自動補正は行わず、Shell／画像アイコン自体の色も変更しません。
